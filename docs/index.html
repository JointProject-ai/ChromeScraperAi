Privacy Policy

Effective Date: May 29, 2025

This privacy policy applies to the Chrome AI Summarizer extension (the "Extension") and explains how your data is handled when you use it. We are committed to protecting your privacy and ensuring transparency.

Overview

This Extension is a lightweight content summarizer that runs primarily in your browser. It processes visible webpage content using Google’s Gemini API (a cloud-based AI service) to generate summaries. It does not collect, store, or sell any personally identifiable information (PII).

1. Information Collected

The Extension does not collect user-identifiable data. However, to provide AI-powered summaries, it sends selected webpage content (only the visible text content of the active tab) to Google's Gemini API for processing. This is done only after the user manually activates the extension.

2. Use of Gemini API

Gemini API is provided by Google and subject to its Privacy Policy and Cloud Terms of Service. The Extension sends:

  • Only visible text content from the current page (e.g., article body, paragraphs)
  • No user credentials, cookies, or sensitive form data are transmitted

We do not have access to or store any of the data processed by Gemini. All requests are ephemeral and stateless.

3. Data We Do Not Collect

The Extension does not collect or transmit any of the following:

  • Names, emails, phone numbers, or personal identifiers
  • IP addresses or geolocation
  • Cookies or tokens
  • User browsing history or cross-tab data
  • Form inputs or login credentials

4. When Content Is Processed

Content is only processed when the user clicks the action button. There is no background or silent scraping. No scheduled or automated requests are made. The request to Gemini is initiated strictly in response to a user command.

5. Real-Time and Stateless Design

The Extension is designed to be stateless. It does not:

  • Store any data on the user’s device (no localStorage, no IndexedDB)
  • Save summaries or inputs
  • Use cookies or tracking pixels

6. No Third-Party Sharing

Except for the Gemini API request for summarization, the Extension does not transmit any information to third parties, advertising networks, or analytics services.

7. Permissions

The Extension uses only the "activeTab" permission, which allows access to the current tab's visible content after user interaction. It does not have access to other tabs, browser history, or personal data.

8. Security

The data is transmitted securely over HTTPS when sent to the Gemini API. No data is stored or logged by the Extension developer.

9. Compliance

This Extension adheres to all applicable Chrome Web Store policies, including the Developer Program Policies and Google's Privacy Policy.

10. Changes

This policy may be updated in response to changes in the Extension or Chrome Store requirements. Any updates will be reflected here.

11. Contact

If you have questions or concerns, please reach out through our GitHub repository.

By using this Extension, you consent to this Privacy Policy and agree to the Gemini API terms as applicable.
